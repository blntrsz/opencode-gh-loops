# Start a task

Invoke `@poteto-mode` with the goal, constraints, and an observable finish condition. The skill selects a playbook and loads the relevant principles. Describe outcomes rather than prescribing a chain of skills.

```text
@poteto-mode fix duplicate submissions. Reproduce first. Done means a regression test and a real UI check proving only one request is sent.
```

OpenCode has no Cursor Custom Mode keyboard shortcut. Ask to continue the style within the session, and invoke it again for a new task when needed. Concurrent writers require separate worktrees and assigned ports/data directories; they do not get cloud VMs automatically.

See [runtime behavior](../../runtime.md) and the [playbook index](../../skills/poteto-mode/SKILL.md).
